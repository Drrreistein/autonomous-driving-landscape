## 投资摘要

阿里巴巴正在经历一场从"电商平台"到"AI基础设施公司"的**战略转型**。FY2026（截至2026年3月）营收突破**1.02万亿人民币**，云业务增速连续加速至40%+，千问大模型月活突破3亿，平头哥GPU实现量产。但代价也同样显著：FY2026资本开支飙至**1269亿人民币**，自由现金流首次转负（-507亿），闪购年亏损约860亿。

**我们给予"买入"评级的核心逻辑：**

1. **云+AI是十年一遇的价值重估催化剂**——云收入FY2027Q1预计同比+45%，AI收入连续11个季度三位数增长
2. **闪购减亏路径清晰**——UE持续改善，管理层指引FY2029实现盈利
3. **估值处于历史低位**——当前PE（TTM）仅18x，PB 1.8x，显著低于全球科技同行
4. **机构一致看多**——19家投行"买入"，目标均价189.51港元，高盛目标180港元，中信建投目标217港元

**主要风险：** 投入期Free Cash Flow为负、闪购亏损超预期、AI商业化慢于预期。

## 三、业务分析

### 3.1 阿里云+AI 🌟 —— 核心价值重估催化剂

**这是当前买入阿里的第一理由。**

| 指标            | 数据           | 重要性          |
| :------------ | :----------- | :----------- |
| FY2026云收入     | ~1,530亿      | **+36% YoY** |
| FY2027Q1云收入前瞻 | **+45% YoY** | 🔥 大超预期      |
| AI收入增速        | 连续11个季度三位数   | 🔥 核心驱动力     |
| 云EBITA利润率     | 9% → 低双位数    | ✅ 盈利改善       |
| 千问App月活       | **突破3亿**     | ✅ 生态拓展       |
| 平头哥GPU        | **已规模量产**    | ✅ 全栈AI能力     |
| 未来资本开支计划      | 3年3,800亿+    | ⚠️ 投入巨大      |

**关键判断**：阿里云已经从"烧钱抢份额"阶段进入"商业化兑现"阶段。云收入增速从FY2024的个位数加速到FY2026Q4的40%+，AI收入占比快速提升，且管理层指引**毛利率拐点将在1-2个季度内出现**。这将是阿里估值体系重构的核心信号。

**ATH事业群**（Alibaba Token Hub）的成立——整合通义实验室、MaaS、千问、悟空等——解决了AI业务内部协同的长期痛点，从"产品导向"转为"Token导向"，有潜力打开阿里云的TAM天花板。

### 3.2 中国电商 —— 稳健现金牛

| 指标           | 数据                 | 评价        |
| :----------- | :----------------- | :-------- |
| FY2026中国电商收入 | ~6,400亿            | +5.8%     |
| CMR增速        | +0.8%（表面）/+7%（同口径） | ⚠️ 口径调整影响 |
| 市场份额         | 稳定                 | ✅ 竞争格局企稳  |

中国电商仍然是阿里的利润基石，虽然增速放缓，但市场份额在激烈的竞争环境中保持稳定。FY2027Q1前瞻显示电商利润同比持平，好于市场预期——这是重要的**盈利底部信号**。

### 3.3 即时零售（淘宝闪购）—— 从烧钱到减亏

| 指标            | 数据        |
| :------------ | :-------- |
| FY2026全年亏损    | ~860亿     |
| Q4日均订单        | ~6,500万单  |
| 单均亏损          | ~3元       |
| Q1 FY2027UE改善 | 快于预期，份额稳定 |

**这是市场最大的分歧点。** 悲观者认为860亿亏损不可持续，乐观者认为UE改善路径清晰（管理层指引FY2029盈利）。Q1 FY2027前瞻显示闪购减亏快于预期、与美团UE差距收窄——这是关键正向信号。

### 3.4 国际电商（AIDC）

FY2026Q4前瞻显示亏损大幅收窄，利润端接近盈亏平衡。AIDC正从"烧钱换增长"转向"效率优先"，国际化版图的盈利拐点可能早于市场预期。

## 六、投资逻辑与风险

### 多头逻辑

1. **AI全栈能力国内最强**——模型（千问）+ 云（阿里云）+ 芯片（平头哥）+ 应用（千问App/支付宝AI版/悟空），这是国内最完整的AI版图
2. **云业务正从投入期进入收获期**——收入加速+利润率提升的双击
3. **闪购亏损收窄快于预期**——即时零售UE拐点可能早于FY2029
4. **估值处于历史低位**——18x PE未反映AI资产价值
5. **持续回购+分红**——提供下行保护

### 空头逻辑

1. **FCF转负**——年投入1,200亿+的AI军备竞赛，回报时间不确定
2. **闪购年亏860亿**——即便减亏，距离盈利仍有3年以上
3. **电商增速放缓**——拼多多/抖音电商的竞争压力长期存在
4. **AI收入能否持续高增长**——三位数增速不可持续，基数效应将在FY2027H2显现
5. **地缘政治/芯片制裁**——美国对华AI芯片出口管制影响长期算力供给

## 八、结论

阿里巴巴正处于**十年一遇的战略转型窗口**——从电商平台变为AI基础设施公司。这个过程伴随着巨大的资本开支和短期利润压力，但方向正确、执行力可追溯、估值已price in了相当多的悲观预期。

我们给予"买入"评级，12个月目标价**155-175港元**。
