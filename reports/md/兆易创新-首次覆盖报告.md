## 投资摘要

兆易创新是全球唯一在 **NOR Flash、利基型DRAM和MCU** 三大领域均排名全球前十的芯片设计公司。当前正处于存储芯片**十年一遇的超级景气周期**——海外大厂系统性退出利基市场，供给缺口持续扩大，产品量价齐升。2026年H1业绩预告：营收~~115亿（+177%），净利~~69亿（**+1099%**），Q2单季净利约54亿，环比Q1增长273%。

**我们给予"增持"评级的核心逻辑：**

1. **存储超级周期至少延续到2027年**——利基DRAM合约价连续上行超过1年，Q3涨价预期持续超预期
2. **公司是全球唯三在三大赛道都有竞争力的企业**——NOR Flash全球第二、MCU国内第一、DRAM爆发式增长
3. **长鑫科技IPO（7月16日申购）**——公司持股1.88%（投资23亿），上市后公允价值将大幅重估
4. **H1净利69亿年化对应Forward PE已降至~29x**，对于增速+1000%的企业并不离谱

**主要风险**：股价250日涨幅390%，短期透支严重；存储周期性强，2027年后价格可能见顶；估值在周期高点面临压缩风险。

## 三、三大业务深度解析

### 3.1 NOR Flash —— 稳健压舱石 🏠

| 指标    | 数据                     |
| :---- | :--------------------- |
| 全球市占率 | **第2名**（仅次于华邦）         |
| 收入占比  | ~35%                   |
| 应用场景  | 服务器BIOS、汽车电子、TWS耳机、IoT |
| 增长驱动力 | AI服务器需求、汽车智能化、端侧AI设备   |

**核心逻辑**：NOR Flash虽然不是最性感的存储品类，但在AI服务器（每台需要多颗NOR存储BIOS）、汽车电子（ADAS/仪表盘/网关）等领域需求持续增长。海外大厂（美光、Cypress）退出中低端市场，为中国厂商留出结构性增长空间。

### 3.2 利基DRAM —— 超级增长引擎 🚀

| 指标          | 数据                               |
| :---------- | :------------------------------- |
| Q1 2026收入   | 环比翻倍+                            |
| 收入占比        | ~33%（Q1），快速上升                    |
| 2026年晶元代工采购 | **57亿**（vs 2025年11.8亿，**+383%**） |
| 涨价周期        | 合约价连续上行超过1年                      |
| 供给格局        | Samsung/SK Hynix/Micron系统性退出利基市场 |

**这是当前兆易创新最大的投资逻辑：**

1. **供给端**：三星、海力士、美光三大DRAM巨头将产能集中于HBM和DDR5，系统性退出DDR3/DDR4等利基市场。剩下的产能无法满足需求。
2. **需求端**：TV、机顶盒、工业控制、物联网设备等对利基DRAM需求稳定甚至增长。
3. **价格走势**：合约价自2025年Q1起持续上行，2026年Q1加速，Q3预期继续超预期。
4. **公司策略**：不追求激进涨价，而是通过与优质客户建立长期关系来扩大市场份额。2026年下半年将实现LPDDR4小容量和新制程DDR4 8Gb量产，并开启LPDDR5研发。

**关键推算**：2026年代工采购57亿，假设毛利率~60%，对应DRAM收入约140亿+。如果全年做到这个量级，DRAM将成为超过NOR Flash的第一大收入来源。

### 3.3 MCU —— 下一个涨价风口 🔜

| 指标   | 数据                          |
| :--- | :-------------------------- |
| 产品线  | 69个系列、700+款产品               |
| 内核覆盖 | ARM Cortex-M23/M3/M4/M33/M7 |
| 国内地位 | **第一大32位MCU供应商**            |
| 涨价态势 | 多家MCU供应商2026年H1密集涨价         |

**核心逻辑**：

- MCU产品价格经历了长期下行，行业基本处于零库存状态
- 由于大量MCU依赖NOR Flash存储代码，存储涨价的涟漪效应已开始向MCU传导
- 多家主要MCU供应商已密集宣布涨价，行业性涨价浪潮正在形成
- 公司MCU覆盖工业、消费、汽车等广泛领域，受益面大

**机器人概念**：单台人形机器人约需100颗MCU，公司产品可覆盖50颗以上，与多家机器人公司合作。这是额外的估值想象力。

### 3.4 SLC NAND —— 意外的爆发机会

海外大厂退出2D NAND市场，SLC NAND面临显著缺货局面，产品价格高增，收入环比强劲增长。公司正在积极研发更高存储密度的产品，2D NAND中期有望成为新的增长引擎。

## 八、结论

兆易创新是A股半导体板块最纯正的存储周期标的。公司基本面极其优秀——全球唯三同时布局NOR+DRAM+MCU的企业、财务干净（147亿现金+零负债）、2026年H1净利暴增1099%。当前Forward PE约29x，对于增速+1000%的企业来说估值合理。

但目前最大的风险不在基本面，而在**股价**——250天涨了390%，从113元到580元。这不是买入一家"被低估"的公司，而是在赌存储超级周期还能持续2-3个季度以上。

**如果你相信存储涨价的逻辑还能延续到2027年Q1，当前价位仍有吸引力（Forward PE 29x→若全年150亿净利则仅27x）。如果你对周期判断不确定，等回调到500-550元再上车是更安全的策略。**

我们给予"增持"评级，12个月目标价**650-780元**。
