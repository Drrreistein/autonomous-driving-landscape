# 智驾产业全貌 · Autonomous Driving Landscape

自动驾驶行业供应链图谱 —— 把这条产业链拆成 **29 个环节、156 家企业、5 个技术等级、8 个应用场景**，并为已覆盖的公司附上调研报告。

**在线访问**：https://drrreistein.github.io/autonomous-driving-landscape/

---

## 首页是什么

首页是一张可交互的供应链图谱，提供三个视角：

| 视角 | 回答的问题 |
| :--- | :--- |
| **供应链图谱** | 钱在各环节怎么分布？谁在上游、谁在中游、谁在运营？ |
| **按技术等级** | L2 / L2+ / L3 / L4 封闭 / L4 开放，各自有哪些玩家？ |
| **按应用场景** | 乘用车、Robotaxi、配送、干线、矿区、港口、车路云 |

带**绿点**的公司名可点击，直达对应的调研报告；无绿点为暂未覆盖。右上角搜索框支持按企业名或环节名实时过滤。

公司名后的小数字（如 `华为 5`）表示该公司横跨 5 个产业链环节——这个标记本身就是信息：**纵向一体化程度越高，越难被单环节的价格战击穿**。

## 图谱的四个层次

**01 上游 · 材料与元器件**
光学与镜头、光电芯片（激光/探测）、车规半导体、晶圆代工、PCB 与连接器、结构件与压铸。

**02 中游 · 感知 / 决策 / 执行 / 软件**
车载摄像头、激光雷达、毫米波雷达、智驾芯片、域控制器、算法与方案、线控执行、车载 OS 与中间件、通信模组。

**03 下游 · 整车与运营**
新势力整车、华为系整车、传统自主整车、商用车、Robotaxi、无人配送、干线物流、矿区、港口与园区。

**04 支撑层**
高精地图与定位、数据标注与仿真、云与训练算力、车路云、保险与检测。

> 支撑层单独成层，而不是塞进"上游"，是因为它不随车出货、也不按 BOM 计价——地图、数据、云算力是**按年付费的能力**，把它放在物料层会误导价值判断。

## 归类口径（重要）

- **主营业环节**：企业按其主要收入来源的环节归类；横跨多环节者（华为、特斯拉、小马智行等）会在多处出现，并标注环节数。
- **技术等级**：按"该企业产品所能支持的最高等级"标注，不等于其已量产的最高等级。芯片与传感器厂商会同时出现在多个等级。
- **应用场景**：按"已落地的运营场景"标注，不含规划中的场景。
- **归类为编辑判断**，非官方口径，不同机构存在分歧。

## 新增一份报告

```bash
# 1. 把 Markdown 原稿放入 reports/md/
cp 某公司-首次覆盖报告.md reports/md/

# 2. 重新生成 HTML（需要 markdown 库）
pip install markdown
python tools/build_reports.py

# 3. 在 index.html 的数据数组 C 中，把该公司的第 5 个字段
#    从 null 改为报告文件名（不含 .md 后缀），即可生成链接
```

数据数组位于 `index.html` 底部 `<script>` 中，格式为：

```js
["公司名", ["环节代码"], ["技术等级"], ["应用场景"], "报告文件名或 null"]
```

环节代码见 `SEG` 对象（u1–u9 / m1–m9 / d1–d11）。
